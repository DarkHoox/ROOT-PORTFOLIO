## Windows Helper PRO – How to Run & Features

### 🚀 How to Run

1. Install Python (version 3.8 or newer recommended).
2. Install the required library:

   ```
   pip install psutil
   ```
3. Copy the program code into a file named:

   ```
   windows_helper_pro.py
   ```
4. Run the script:

   ```
   python windows_helper_pro.py
   ```
5. (Important) Run the program as **Administrator** for full functionality:

   * Right-click Command Prompt → "Run as administrator"
   * Then run the script from there

---

### 🧠 Features

**🧹 Clean Temporary Files**

* Deletes temporary files from system folders
* Frees up disk space

**🌐 Network Repair**

* Resets DNS cache
* Renews IP address
* Fixes Winsock issues
* Helps resolve common internet problems

**🔍 System File Check (SFC)**

* Scans and repairs corrupted Windows system files
* Uses built-in Windows tool (`sfc /scannow`)

**🧠 System Diagnostics**

* Displays CPU, RAM, and disk usage
* Warns if system resources are heavily used

**🚀 Fix All (One-Click Repair)**

* Runs all major fixes automatically:

  * Disk cleanup
  * Network reset
  * System file check
  * Diagnostics

**📊 Progress Bar**

* Shows completion progress during operations

**📝 Activity Log**

* Displays real-time actions and results inside the app

**⚡ Responsive UI**

* Uses multithreading to prevent freezing during long operations

---

### ⚠️ Notes

* Some operations may take several minutes (especially SFC scan)
* Restarting your PC after using the tool is recommended
* Administrator privileges are required for full functionality

---

### 💡 Summary

Windows Helper PRO is a simple all-in-one troubleshooting tool for Windows 11 that helps fix common issues like slow performance, network errors, and system file corruption with just a few clicks.
